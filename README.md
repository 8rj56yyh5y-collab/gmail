# Gobsek Mail

Рассылка писем европейским компаниям, каждой на её языке, и сбор ответов во «Входящие».

Загружаете файл со списком компаний (Excel или CSV). Система определяет страну каждой компании и выбирает
письмо на нужном языке: Германия и Австрия получают немецкое, Испания испанское, Франция и Бельгия французское.
Письма уходят по одному с паузой. Ответы компаний собираются во «Входящих» и пересылаются на рабочую почту.

Оформление такое же, как у Gobsek и БХ Учёт: шрифт Onest, светлая и тёмная тема, боковое меню на компьютере,
нижнее меню на телефоне. Приложение можно поставить на экран «Домой».

## Как это работает

1. **Загрузить файл.** Подходит Excel (.xlsx) или CSV, можно просто вставить строки из таблицы.
   Система сама находит колонки «почта», «страна», «название» и понимает заголовки на русском, украинском,
   английском, немецком и других языках. Перед добавлением каждую колонку можно поправить.
   - Страну можно написать как угодно: `Germany`, `Deutschland`, `Германия`, `DE`. Если страны нет, она определяется по домену почты (`.de`, `.fr`, `.es`…).
   - Если в ячейке несколько адресов, каждый станет отдельной строкой.
   - Повторы по почте пропускаются, но пустые поля у уже известной компании дополняются.
   - Остальные колонки (отрасль, город, заметки) сохраняются в карточке компании.
2. **Шаблоны писем.** Для каждого языка есть первое письмо и короткое напоминание. Сначала там лежат черновики
   на английском, немецком, французском и испанском — замените их своими текстами. Данные подставляются сами:
   `{{company}}`, `{{name|Sir or Madam}}`, `{{my_company}}`, `{{signature}}`… Справа видно, как письмо увидит компания.
   К письму можно приложить файл, например PDF-презентацию. Перед рассылкой письмо можно отправить себе для проверки.
3. **Новая рассылка.** Выбираете, кому писать: всем новым, по странам, по языкам, из конкретного файла или
   отмеченным в списке. Перед запуском видно, сколько писем уйдёт на каждом языке. Если для какого-то языка письма нет,
   уйдёт английское (или такие компании можно пропустить).
4. **Отправка.** Письма уходят по одному со случайной паузой (по умолчанию 1–2,5 мин), только в рабочее время
   получателей (пн–пт, 8:00–18:00 по Берлину) и не больше дневного лимита (по умолчанию 120 в сутки).
   Это защищает от спама и от блокировки ящика. Если через 5 дней ответа нет, в ту же переписку уходит напоминание (можно отключить).
5. **Входящие.** Каждые 2 минуты система читает «Входящие» почтового ящика и берёт оттуда только ответы на наши письма.
   - Ответ показывается в переписке с компанией, напоминание этой компании отменяется.
   - Каждый ответ пересылается на рабочую почту (`FORWARD_TO`). Если нажать там «Ответить», письмо уйдёт прямо компании.
   - Если компания пишет «unsubscribe / abmelden / baja / désinscrire…», она попадает в стоп-лист.
   - Автоответы («Out of office», «Abwesenheit») и сообщения о недоставке лежат в отдельных вкладках.
     Компания с несуществующим адресом исключается из рассылок.
   - Ответить можно прямо из системы: письмо уйдёт с вашего ящика в ту же цепочку.
   - Остальная почта в ящике остаётся как есть: ничего не удаляется и не помечается прочитанным.
6. **Перевод (необязательно).** Если задан `ANTHROPIC_API_KEY`, доступны три кнопки:
   - «Перевести на русский» в каждом ответе;
   - «Перевести на немецкий/французский…» для вашего ответа: пишете по-русски, отправляете на языке компании;
   - «Перевести шаблон» — новый язык из существующего письма.

## Подключение Gmail

1. Включите двухэтапную проверку: https://myaccount.google.com/signinoptions/twosv
2. Создайте пароль приложения: https://myaccount.google.com/apppasswords (название, например, «Gobsek Mail»).
3. В системе откройте **Настройки → Почта**, выберите Gmail, введите адрес и 16 символов пароля и нажмите **«Проверить подключение»**.

Обычный пароль от Gmail не подойдёт. Подходят и другие ящики: Outlook, Yahoo, Zoho, ukr.net или любой с SMTP/IMAP.

> Лимиты Gmail: обычный ящик — до ~500 писем в сутки, Google Workspace — до ~2000. Новым ящикам лучше начинать
> с 50–100 писем в день. Для писем в Европу полезно указать в подписи компанию и контакты и оставить строку
> об отписке (она включена по умолчанию).

## Запуск

Нужен Node.js 22.13+.

```bash
npm install
```

```bash
ADMIN_LOGIN=admin ADMIN_PASSWORD='Пароль123' npm start
```

Откройте http://localhost:3000. Если `ADMIN_PASSWORD` не задан, временный пароль печатается в консоли при первом запуске.

Посмотреть на демо-данных (36 вымышленных компаний, письма никуда не уходят):

```bash
ADMIN_PASSWORD='Demo12345' npm run demo
```

```bash
npm test
```

### Переменные окружения

| Переменная | Что делает |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `DATA_DIR` | где хранить базу и вложения (по умолчанию `./data`) |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_NAME` | первый вход (создаётся при первом запуске) |
| `MAIL_USER`, `MAIL_PASSWORD` | почтовый ящик (вместо ввода в настройках) |
| `SMTP_HOST`, `SMTP_PORT`, `IMAP_HOST`, `IMAP_PORT` | серверы почты, если не из списка |
| `FROM_NAME` | имя отправителя |
| `FORWARD_TO` | куда пересылать ответы компаний |
| `APP_SECRET` | ключ шифрования пароля почты в базе (иначе создаётся файл `data/.secret`) |
| `ANTHROPIC_API_KEY` | включает перевод писем |
| `AI_MODEL` | модель для перевода (по умолчанию `claude-opus-5-5`) |
| `COOKIE_SECURE=1`, `TRUST_PROXY=1` | для работы по HTTPS за прокси (Render и т. п.) |
| `MAIL_TRANSPORT=json` | тестовый режим: письма никуда не уходят |

## Где запустить

Рассылка и проверка почты работают, пока работает сервер.

- **Со своего Mac.** Двойной клик по `start-mac.command`. Скрипт установит всё нужное, создаст пароль (сохранится в `.env.local`)
  и покажет временную ссылку `https://xxxx.trycloudflare.com`. Письма уходят, пока окно Терминала открыто и Mac не спит.
- **Постоянно, на Render.com.** https://dashboard.render.com → **New → Blueprint** → этот репозиторий → **Apply**.
  Заполните `ADMIN_LOGIN`/`ADMIN_PASSWORD`; почту можно подключить сразу (`MAIL_USER`, `MAIL_PASSWORD`, `FORWARD_TO`) или позже в настройках.
  Нужен тариф Starter с диском (~7 $/мес): бесплатный «засыпает», и рассылка останавливается.

## Устройство

```
server/index.js      HTTP-сервер, маршруты, настройки
server/importer.js   разбор Excel/CSV, угадывание колонок
server/countries.js  страна → язык, распознавание названий стран
server/templates.js  шаблоны, подстановка данных, черновики писем
server/mailer.js     очередь, паузы, лимиты, напоминания, ответы, пересылка (SMTP)
server/inbox.js      чтение ящика (IMAP), ответы, отписки, автоответы, недоставка
server/contacts.js   компании: список, фильтры, стоп-лист
server/ai.js         перевод (Claude, необязательно)
server/db.js         SQLite, шифрование пароля почты
server/demo.js       демо-данные
public/              интерфейс без фреймворков (дизайн Gobsek)
tests/               сквозной тест: файл → рассылка → ответы
```
